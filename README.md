
# M.E.V.A — Mars Exploration and Virtual Adventure

**Explore Mars. Experience the Impossible.**

M.E.V.A is an interactive Mars exploration project developed for the NASA Space Apps Challenge 2026.

This repository contains the official project landing page, designed to introduce the experience, showcase its technologies, and provide access to the application and scientific documentation.

## About the Project

M.E.V.A brings Martian exploration closer to Earth through scientific data, interactive mission planning, and immersive 3D experiences.

The project combines two experiences:

- **Marswalk Planner:** Plan exploration routes, analyze environmental conditions, estimate resources, and evaluate mission safety.
- **3D Exploration Simulator:** Experience the Martian surface through an immersive first-person environment.

## Landing Page Features

- Responsive interface built with React
- Animated space background with parallax effects
- Subtle Liquid Glass design
- Interactive FAQ section
- Project documentation and scientific references
- Technology overview
- Direct access to the original project

## Technologies

The landing page was developed using:

- React
- Vite
- JavaScript
- CSS3
- GSAP & ScrollTrigger
- Inter typography

The M.E.V.A application also uses technologies such as Leaflet and Three.js, alongside scientific data from NASA and USGS.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Joaovitor-bot/meva-landing-page.git
```

Navigate to the project:

```bash
cd meva-landing-page
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed in your terminal.

## Production Build

```bash
npm run build
npm run preview
```
